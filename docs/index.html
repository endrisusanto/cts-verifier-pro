CTS Verifier Pro

Sistem otomasi desktop kelas industrial untuk validasi perangkat Android melalui Android Compatibility Test Suite (CTS) Verifier. Dirancang untuk skalabilitas, efisiensi, dan akurasi dalam pengujian multi-device secara simultan.

Fitur Utama

Multi-Device Orchestration

Kelola dan jalankan pengujian pada puluhan perangkat sekaligus dari satu dashboard pusat tanpa konflik resource.

Auto-Dependency Injection

Mendeteksi versi Android secara otomatis dan memasang APK pendukung yang sesuai (Android 13 hingga Android 16).

Result Aggregation

Penarikan hasil pengujian otomatis langsung ke folder terstruktur, lengkap dengan penamaan berdasarkan Serial dan Model perangkat.

Industrial Dashboard

Visualisasi progres real-time, log konsol mendalam untuk setiap perangkat, dan kontrol darurat (Emergency Stop).

Penting: Manajemen Resource

Karena batasan ukuran file di GitHub, file Resource APK (Asset pengujian) tidak dibundel di dalam installer. Anda harus menyalin folder resource secara manual dari storage internal tim.

Panduan Instalasi & Persiapan

1. Persiapan Lingkungan

  • Pastikan ADB (Android Debug Bridge) sudah terpasang di sistem dan masuk ke dalam PATH.
  • Aktifkan USB Debugging di semua perangkat yang akan diuji dan pastikan statusnya authorized.

2. Struktur Folder Resource

Aplikasi mencari folder resources/ di direktori kerja. Struktur folder yang benar adalah sebagai berikut:

resources/
├── ApkTest/
│   ├── AutoCtsVerifier-debug.apk
│   └── AutoCtsVerifier-debug-androidTest.apk
└── Normal/
    ├── 13/ (APK khusus Android 13)
    ├── 14/ (APK khusus Android 14)
    ├── 15/ (APK khusus Android 15)
    └── 16/ (APK khusus Android 16)

3. Konfigurasi Lokasi

Jika Anda ingin meletakkan resource di lokasi berbeda, gunakan Environment Variable:

# Linux / macOS
export CTS_VERIFIER_RESOURCE_DIR=/jalur/ke/folder/resource

# Windows (PowerShell)
$env:CTS_VERIFIER_RESOURCE_DIR = "C:\jalur\ke\folder\resource"

Alur Kerja Pengujian

  1. Refresh Devices: Hubungkan perangkat dan tekan tombol Refresh untuk mendeteksi ID, Model, dan Versi Android.
  2. Get Testcases: Pilih perangkat yang diinginkan, lalu klik "Get Testcases" untuk memuat daftar pengujian yang relevan.
  3. Run Selected: Jalankan otomasi. Aplikasi akan memasang APK dependensi dan menjalankan paket pengujian secara berurutan.
  4. Collect Results: Setelah selesai, klik "Get Results" untuk menarik seluruh laporan dari perangkat ke direktori lokal Anda.

Pemecahan Masalah

Berikut adalah solusi untuk kendala yang sering ditemui:

  • Device Unauth: Periksa pop-up izin di layar handphone dan centang "Always allow".
  • Resources Not Found: Pastikan folder resources/ berada di lokasi yang benar atau variable env sudah diset.
  • Build Gagal: Pastikan driver USB pabrikan (Samsung/Google/dll) sudah terpasang dengan benar di Windows.
