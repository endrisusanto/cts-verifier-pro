Install Steps

  1. Unduh installer sesuai OS dari release terbaru.
  2. Unduh juga cts-verifier-resources.zip.
  3. Install aplikasinya.
  4. Ekstrak file zip menjadi folder resources/.
  5. Letakkan folder resources/ di samping binary aplikasi, atau gunakan environment variable.
CTS_VERIFIER_RESOURCE_DIR=/path/to/resources

Release Flow

Project ini memakai GitHub Actions untuk draft release otomatis saat tag v* di-push.

git checkout main
git pull
git tag -a v1.4.0 -m "Release v1.4.0"
git push origin v1.4.0
  • Workflow build asset deb, rpm, dan exe.
  • Workflow juga membuat cts-verifier-resources.zip.
  • Hasilnya dikirim ke draft GitHub Release untuk direview sebelum publish.
